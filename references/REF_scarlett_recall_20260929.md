# REF：Scarlett 召回鏈路（Owner 提供的參考框架）

收錄：2026-09-29 規劃窗。來源：Owner 分享的其他老師作品（小紅書號 456654719a），原圖存 `REF_scarlett_recall_20260929.jpg`。
Owner 原話：「整張都能參考 包含文字/圖片/多模態等等的 我們之後優化記憶功能也能直接參考或者照搬」。
性質：**第三方參考資料**，不是我們系統的現況陳述；照搬前逐項對我們的實況驗證。

## 核心原則

- 被動浮現：她說一句話 → 一輪**最多浮一條**記憶（0♥1）；浮不上來，AI 自己主動去翻（獨立的「我自己翻」路徑）。
- 召回鏈路**只讀記憶庫、從不改寫**；糾錯是唯一寫入口（只提交修正，不刪任何東西）。
- **給原文不給摘要**：命中成卷的故事給整卷；否則給單條原文＋日期＋當時的圖＋歸屬指針。
- 寧缺毋濫：都不相關 = 不浮，這一輪什麼都不給；門檻下的永不遞補。

## 三條通道（共用出口與冷卻）

1. **主干浮現**：哨兵（小模型讀 query 提煉話題/關鍵詞/日期/要點；失敗不靜默→退回直連召回並留日誌）→ 語義榜＋關鍵詞榜**雙榜互相補盲** → RRF 按名次融合（只看名次不看分數）→ 語義門檻 → 冷卻/去重 → 灰區複判 → 只取一條。
2. **專名匹配**：她親手寫的專名庫（人/地方/梗/物件，各有本名+別名）；話裡含名就命中，單字不算、單個 emoji 算；獨立冷卻、第一句就生效、不受開窗前幾輪限制。
3. **圖召回**：哨兵判「她在找以前的圖」→ 文字話題轉圖向量直搜；排除當前窗口的圖、同圖去重、共用冷卻最多幾張、最後交給 Read 看圖確認。

## 閘門細節（順序：前面便宜、後面貴）

門檻 → 冷卻 → 整卷拉黑 → 語義去重 → 按融合名次收前幾 → 灰區複判 → 只取一條。

- 語義門檻統一檔位；哨兵提煉失敗退回原句、按句子長短分檔。
- 語義去重：和已在上下文或已收候選高度重疊＝「同一件事換了件衣服」，跳過。
- 整卷拉黑：一段故事整卷給過之後，卷裡所有碎片（含之後新加的）都不再浮。
- 冷卻**寫穿資料庫**，進程重啟不復燙；過期允許回來，當長期壓箱底的救生索。
- 核心記憶已注入的（CC 路徑出生自帶）預填「已推過」；直連路徑不預填。
- 灰區複判：有把握的直接放行；拿不準的前幾名交複判重排，取最高且過線；複判出錯照原第一名，不比以前差。

## 入口紀律

- **只召回她自己說的話**：系統輪、儀式鍵、工作窗的句子都不觸發。
- 開窗前幾輪讓給出生儀式（新窗先帶整套核心記憶；重 roll 不重判、進程重啟不會重判亂序）。
- 正則兜底：「上次」「還記得」「說過」一出現就強制翻，防哨兵漏判。
- 關鍵詞退化鏈：稀缺關鍵詞 → 話題 → 原句，每一級分詞後不為空才用。
- 時間寬收窄選、前後放寬一天；窗口裡沒記憶就落回全集，不混語義。

## 復盤與工程

- **路由日誌**每輪一行：翻沒翻、話題、關鍵詞、日期、命中、為什麼浮/不浮；**透視窗**：回覆芯片顯示浮了哪條、兩張榜的名次。
- **錯題集**：她點的每一個叉都存檔；同一題一條只記一次，快照不隨記憶庫改動。**測評集**：閒聊不該召、該召哪條、禁止召黑條——一題一題驗，改參數先過一遍。
- **調參台**：參數熱重載（surface-tuning.json，不用重啟）；融合是純函數（fusion.js 零依賴、能單測、能離線掃參）；**生產和調參台共用同一份裝配核**（assembleBoards / applyDateFilter / surfaceThreshold / rerankGate）不漂移。
- 冷卻持久化（surface_cooldown / meme_cooldown 寫穿資料庫）；小模型可換（哨兵掛管理台，換模型不改碼）；**分詞兩側對齊**（索引和查詢共用 cutForSearch，自定義詞典專名優先）。

## 不做什麼

不每輪塞一把 top-k／不拿門檻下的遞補／不把時間詞混進語義／不推已在上下文裡的／不給摘要不轉述／不靜默降級／不改寫記憶庫／不召回不是她說的話／不讓碎片搶出生儀式／不永久拉黑單條記憶。
