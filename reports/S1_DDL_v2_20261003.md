## 依序執行的 DDL（單一 transaction 內）

### 1.

```sql
CREATE TABLE IF NOT EXISTS memory_eligibility (
    memory_id     TEXT PRIMARY KEY REFERENCES memories(memory_id) ON DELETE CASCADE,
    state         TEXT NOT NULL CHECK (state IN ('hidden','superseded','dormant')),
    superseded_by TEXT REFERENCES memories(memory_id) ON DELETE RESTRICT,
    reason        TEXT NOT NULL,
    set_by        TEXT NOT NULL,
    set_at        TEXT NOT NULL,
    CHECK (state <> 'superseded' OR (superseded_by IS NOT NULL AND superseded_by <> memory_id))
);
```

### 2.

```sql
CREATE TABLE IF NOT EXISTS memory_eligibility_log (
    log_id        INTEGER PRIMARY KEY AUTOINCREMENT,
    memory_id     TEXT NOT NULL,
    action        TEXT NOT NULL,
    state         TEXT,
    superseded_by TEXT,
    reason        TEXT,
    set_by        TEXT NOT NULL,
    at            TEXT NOT NULL
);
```

### 3.

```sql
CREATE TABLE IF NOT EXISTS memory_protection (
    memory_id TEXT NOT NULL REFERENCES memories(memory_id) ON DELETE RESTRICT,
    kind      TEXT NOT NULL CHECK (kind IN ('mistake_answer','incident_record','owner_keep')),
    ref       TEXT NOT NULL,
    set_by    TEXT NOT NULL,
    set_at    TEXT NOT NULL,
    PRIMARY KEY (memory_id, kind, ref)
);
```

### 4.

```sql
CREATE TABLE IF NOT EXISTS memory_evidence (
    memory_id     TEXT NOT NULL REFERENCES memories(memory_id) ON DELETE CASCADE,
    term          TEXT NOT NULL CHECK (length(term) > 0),
    first_seen_at TEXT NOT NULL,
    last_seen_at  TEXT NOT NULL,
    seen_count    INTEGER NOT NULL DEFAULT 1 CHECK (seen_count >= 1),
    PRIMARY KEY (memory_id, term)
);
```

### 5.

```sql
CREATE TABLE IF NOT EXISTS injection_events (
    event_id  INTEGER PRIMARY KEY AUTOINCREMENT,
    memory_id TEXT NOT NULL,
    path      TEXT NOT NULL,
    caller    TEXT DEFAULT 'unknown',
    at        TEXT NOT NULL
);
```

### 6.

```sql
CREATE INDEX IF NOT EXISTS idx_injection_events_mid_at ON injection_events(memory_id, at);
```

## 執行程式（逐字）

```python
    Y2C_OBJECTS = {"memory_eligibility": "table", "memory_eligibility_log": "table", "memory_protection": "table",
                   "memory_evidence": "table", "injection_events": "table", "idx_injection_events_mid_at": "index"}

    @staticmethod
    def _norm_sql(sql: str) -> str:
        sql = re.sub(r"\s+", " ", (sql or "").strip())
        sql = re.sub(r"\s*([(),])\s*", r"\1", sql)
        return re.sub(r"(?i)^CREATE (TABLE|INDEX) IF NOT EXISTS ", r"CREATE \1 ", sql)

    @classmethod
    def _y2c_expected_sql(cls) -> dict:
        """在記憶體裡照 DDL 建一次，取 sqlite_master 的正規化 SQL 當「預期 schema」。"""
        mem = sqlite3.connect(":memory:")
        try:
            mem.execute("CREATE TABLE memories (memory_id TEXT PRIMARY KEY)")
            for ddl in cls.Y2C_DDL:
                mem.execute(ddl)
            return {n: (t, cls._norm_sql(s)) for n, t, s in
                    mem.execute("SELECT name, type, sql FROM sqlite_master WHERE name IN (%s)" %
                                ",".join("?" * len(cls.Y2C_OBJECTS)), list(cls.Y2C_OBJECTS))}
        finally:
            mem.close()

    def _y2c_schema_problems(self, conn, require_all: bool) -> list:
        """與預期 schema 逐物件比對（型別＋正規化後的完整 SQL，含 FK／CHECK／ON DELETE）。"""
        expected = self._y2c_expected_sql()
        actual = {n: (t, self._norm_sql(s)) for n, t, s in
                  conn.execute("SELECT name, type, sql FROM sqlite_master WHERE name IN (%s)" %
                               ",".join("?" * len(self.Y2C_OBJECTS)), list(self.Y2C_OBJECTS))}
        problems = []
        for name, want in expected.items():
            got = actual.get(name)
            if got is None:
                if require_all:
                    problems.append(f"missing {name}")
            elif got != want:
                problems.append(f"incompatible {name} ({got[0]})")
        return problems

    def _migrate_y2c(self):
        conn = self._conn()
        try:
            row = conn.execute("SELECT value FROM schema_meta WHERE key='y2c_schema'").fetchone()
            version = row[0] if row else None
            if version is not None and version != Y2C_SCHEMA_VERSION:
                raise Y2cSchemaError(f"y2c_schema={version!r} != {Y2C_SCHEMA_VERSION!r}; refusing to migrate")
            if version == Y2C_SCHEMA_VERSION:
                problems = self._y2c_schema_problems(conn, require_all=True)
                if problems:
                    raise Y2cSchemaError("y2c schema marked current but does not match: " + "; ".join(problems))
                return
            problems = self._y2c_schema_problems(conn, require_all=False)  # 首次施工：盤點同名物件
            if problems:
                raise Y2cSchemaError("pre-existing objects conflict with y2c schema: " + "; ".join(problems))
            conn.execute("BEGIN IMMEDIATE")
            for ddl in self.Y2C_DDL:
                conn.execute(ddl)
            conn.execute("INSERT INTO schema_meta (key, value, updated_at) VALUES ('y2c_schema', ?, ?)",
                         (Y2C_SCHEMA_VERSION, datetime.utcnow().isoformat()))
            problems = self._y2c_schema_problems(conn, require_all=True)
            if problems:
                raise Y2cSchemaError("post-migration verification failed: " + "; ".join(problems))
            conn.execute("COMMIT")
        except Exception:
            if conn.in_transaction:
                conn.execute("ROLLBACK")
            raise
        finally:
            conn.close()
```

## 回退（雙軌，兩軌一起做）

**① DB rollback**。⚠ **僅適用 S1，或尚未承載正式資料的階段。** S2 開始寫入正式資料（hidden、保護、證據、注入事件）之後，DROP 會丟資料，屆時需另訂保資料的 rollback。

```sql
BEGIN IMMEDIATE;
DROP TABLE IF EXISTS injection_events;          -- 連帶刪除 idx_injection_events_mid_at
DROP TABLE IF EXISTS memory_evidence;
DROP TABLE IF EXISTS memory_protection;
DROP TABLE IF EXISTS memory_eligibility_log;
DROP TABLE IF EXISTS memory_eligibility;
DELETE FROM schema_meta WHERE key = 'y2c_schema';
COMMIT;
```

（也可以直接還原套用前的 `.backup` 檔。）

**② code rollback**：二擇一——
- `git -C /root/anchor-memory reset --hard 3834bdd`（S1 之前的 HEAD）；
- `git revert` 由 `git am 0001` 產生的那個 commit（patch 來源：staging 61c59e4）。

只做 ① 不做 ②：下次開庫會把表建回來。只做 ② 不做 ①：表會留著，舊程式不讀，行為不受影響。
