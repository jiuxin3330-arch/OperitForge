## 三、embedder 圍欄方案（實測）

- **結論：復原本身不需要 embedder**。向量本來就在，0014 只建表列，不載入模型，所以在停機窗內完成，總共約 0.1 秒、17 MB。

  - 實測（快照 20261007r，transient unit，MemorySwapMax=0）：
    - **MemoryMax=900M 時被 OOM 殺掉**（cgroup 記錄 900M 封頂），這個失敗也照實記下；

    - 不在關鍵路徑上；
    - MemAvailable < 1400 MB 時直接拒跑；
    - 只跑在新快照副本上，不碰正式庫。
  - 今天已經量過、結果全對，**建議開閘時不再跑**；規劃窗若想在當下再驗一次，在服務外跑，約 16 秒。

## 五、Runbook

```
cd /root/anchor-eval; P=/root/anchor-memory/venv/bin/python
$P -B scripts/s2r_gate.py preflight          # 唯讀全套（見下）
$P -B scripts/s2r_gate.py apply              # dry-run：印出完整計畫與喚醒狀態
systemd-run --unit=s2p-gate-s2r-apply-$(date +%s) --collect -p WorkingDirectory=/root/anchor-eval -p StandardOutput=append:/root/anchor-eval/logs/s2r-apply.log -p StandardError=append:/root/anchor-eval/logs/s2r-apply.log $P -u -B scripts/s2r_gate.py apply --execute
nohup $P -B scripts/s2r_gate.py parity --execute > logs/s2r-gate-parity.log 2>&1 &   # 裝後 parity（旗標關），必須 IDENTICAL
$P -B scripts/s2r_gate.py verify

```
