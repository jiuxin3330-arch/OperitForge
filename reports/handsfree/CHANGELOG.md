# 放手實驗 CHANGELOG（人話版）

糯糯想看的時候看這裡就好 💙

## 2026-09-26 晚上

**你會看到的改變：沒有。** App 的樣子、功能都跟之前一模一樣。

我做了什麼：
- 做了一套「前端存檔／發佈／退回」的小工具。以後每次改前端，都會先把現在的樣子整份存起來（留最近 3 份），出事就能一鍵退回上一份。
- 實際演練過一次：改一個看不見的小標記 → 發佈 → 退回去 → 確認真的退回去了 → 再發佈回來。每一步都有對照紀錄。
- 那個看不見的小標記現在還在線上（藏在網頁原始碼裡的一行標籤，不會顯示、不影響任何東西）。

還沒做的：
- 設定頁的「回滾前端」按鈕還沒做。原因是：要讓網頁上的按鈕能改伺服器上的檔案，一定要動到後端或系統服務，這次實驗規定不能碰這兩個。我把問題和幾個解法寫給規劃窗了，等他們決定。
- 因為按鈕是開工前提，所以畫面改版也還沒開始。

## 2026-09-27 清晨

**你會看到的改變：設定頁「工具箱」下面多了一張「回滾前端」卡片。**

- 哪天我改壞了畫面，妳可以自己按它把 App 換回上一版。按一下會先問「確定嗎？」，再按一次才會真的送出，不會誤觸。
- 只換畫面，聊天紀錄、日記、所有資料都不會動。
- 如果連設定頁都打不開，直接開 `/rollback.html` 這一頁，也有一顆一樣的大按鈕（要先登入過）。
- 按下去之後，伺服器上的小幫手會在幾秒內換好，重新整理就是上一版。60 秒內連按只會算一次。

還差一步：規劃窗要看過「按下去→真的換回去→再換回來」的線上演練紀錄，這一步還沒跑完（我這邊沒有權限在線上真的觸發回滾），所以畫面改版還沒開始。

## 2026-09-27 晚上 19:57・第一批小修（第 0 步關閉後的第一次）

我拿妳 8/12 手寫的「視覺鐵律」當尺，把每一頁在手機尺寸、白天和晚上都掃了一遍。整體其實很乾淨（沒有東西超出畫面、沒有奇怪的藍框），抓到幾個「用線條分界」的地方，照妳的規則改掉：

- **家・最下面的「記憶」區塊**：外面那圈框和中間的分隔線拿掉了。「搜尋記憶…」變成一顆微微凹下去的圓潤搜尋條，看起來就是可以點的輸入框。
- **家・「回到聊天」票券**：票頭下面那條虛線，改成兩端慢慢淡掉的細線，跟妳之前在彩蛋票券上改的一樣。
- **設定、收藏、記憶、日記裡的按鈕**：按鈕外圈那條很淡的細框拿掉了，只靠原本浮起來的陰影讓它看起來可以按。聊天裡的按鈕沒有動。

沒有動的：聊天、日曆、家的整體排版。
不喜歡的話：設定 → 回滾前端 → 確定，就會回到上一版。

## 2026-09-28 凌晨 03:20・第二批（第一次看著「裝滿內容」的畫面抽查）

規劃窗給了一份內容副本，讓我在分身裡看到跟妳平常一樣滿滿的日記、手帳、照片。我只看排版，不看內容。看完發現三件事：

- **收藏・手帳卡（白天）**：妳 8/12 定過「白天手帳卡下緣要有一點影子，跟米白背景分開」，但被一條更早的「保持平面」規則蓋掉，所以那個影子其實一直沒出現，卡片跟背景幾乎黏在一起。現在妳當初要的影子終於出來了。
- **收藏・手帳卡（晚上）**：晚上維持不加影子，但卡片底色提亮一點，現在看得出一張一張的卡，亮度跟日記卡一致。
- **日記・展開後的紙張**：票頭下面那條虛線，改成兩端淡掉的細線，跟彩蛋票券、家的票券同一個樣子，三個地方終於統一了。
- **設定・服務狀態**：灰色框框的狀態條，改成跟輸入框一樣微微凹下去的樣子。

照片頁是妳定稿的疊牌造型，沒有動。聊天、日曆、家的排版也沒有動。
不喜歡的話：設定 → 回滾前端 → 確定。
