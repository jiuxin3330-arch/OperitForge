# S1-DDL：TICKET-Y Y2c S1 的完整 DDL（送小踢獨立審）

- **來源**：/root/anchor-eval/patches/y2c/0001（staging commit 222b5bd，檔案 anchor_y2c.py 的 `Y2cMixin.Y2C_DDL`）。
- **逐字照錄**：下列每一句都由程式從原始碼直接匯出，沒有人工改寫。
- **對象**：/root/anchor-memory 的 memories.db（SQLite 3.45.1）。
- **作用範圍**：只新增五張表、一個索引，以及 schema_meta 裡的一列版本記錄。**不改任何既有表、不加任何欄位，也沒有任何讀取路徑**。
- **執行時機**：AnchorDB 開庫時，`_init_tables()` 依序跑完 `_migrate_ticketq()` 後，呼叫 `_migrate_y2c()`。
- **單一 transaction**：以 `BEGIN IMMEDIATE` 開始，全部成功才 `COMMIT`；任一句失敗就 `ROLLBACK` 並把例外往上丟，整批都不落地。
- **外鍵**：開庫連線一律先執行 `PRAGMA foreign_keys = ON`（anchor_db._conn），所以下面 REFERENCES 宣告的 ON DELETE 行為都會生效。
- **版本標記**：成功後 schema_meta 會寫入 `y2c_schema = y2c-s1-2`（INSERT OR IGNORE）。

## 依序執行的 DDL

### 1.

```sql
CREATE TABLE IF NOT EXISTS memory_eligibility (
    memory_id     TEXT PRIMARY KEY REFERENCES memories(memory_id) ON DELETE CASCADE,
    state         TEXT NOT NULL CHECK (state IN ('hidden','superseded','dormant')),
    superseded_by TEXT,
    reason        TEXT NOT NULL,
    set_by        TEXT NOT NULL,
    set_at        TEXT NOT NULL,
    CHECK (state <> 'superseded' OR (superseded_by IS NOT NULL AND superseded_by <> memory_id))
);
```

### 2.

```sql
CREATE TABLE IF NOT EXISTS memory_eligibility_log (
    log_id        INTEGER PRIMARY KEY AUTOINCREMENT,
    memory_id     TEXT NOT NULL,
    action        TEXT NOT NULL,
    state         TEXT,
    superseded_by TEXT,
    reason        TEXT,
    set_by        TEXT NOT NULL,
    at            TEXT NOT NULL
);
```

### 3.

```sql
CREATE TABLE IF NOT EXISTS memory_protection (
    memory_id TEXT NOT NULL REFERENCES memories(memory_id) ON DELETE RESTRICT,
    kind      TEXT NOT NULL CHECK (kind IN ('mistake_answer','incident_record','owner_keep')),
    ref       TEXT NOT NULL,
    set_by    TEXT NOT NULL,
    set_at    TEXT NOT NULL,
    PRIMARY KEY (memory_id, kind, ref)
);
```

### 4.

```sql
CREATE TABLE IF NOT EXISTS memory_evidence (
    memory_id     TEXT NOT NULL REFERENCES memories(memory_id) ON DELETE CASCADE,
    term          TEXT NOT NULL,
    first_seen_at TEXT NOT NULL,
    last_seen_at  TEXT NOT NULL,
    seen_count    INTEGER NOT NULL DEFAULT 1,
    PRIMARY KEY (memory_id, term)
);
```

### 5.

```sql
CREATE TABLE IF NOT EXISTS injection_events (
    event_id  INTEGER PRIMARY KEY AUTOINCREMENT,
    memory_id TEXT NOT NULL,
    path      TEXT NOT NULL,
    caller    TEXT DEFAULT 'unknown',
    at        TEXT NOT NULL
);
```

### 6.

```sql
CREATE INDEX IF NOT EXISTS idx_injection_events_mid_at ON injection_events(memory_id, at);
```

### 版本列（同一 transaction 內）

```sql
INSERT OR IGNORE INTO schema_meta (key, value, updated_at) VALUES ('y2c_schema', 'y2c-s1-2', <utcnow ISO>);
```

## 外鍵與刪除語義一覽

| 表 | 外鍵 | ON DELETE | 主鍵／唯一 | 用途 |
|---|---|---|---|---|
| memory_eligibility | memory_id → memories | CASCADE | PK(memory_id) | 現況表：hidden／superseded／dormant；沒有列＝eligible |
| memory_eligibility_log | （無；刻意不設，歷史列要比記憶本身活得久） | — | PK(log_id) AUTOINCREMENT | append-only 歷史 |
| memory_protection | memory_id → memories | **RESTRICT** | PK(memory_id, kind, ref) | 錯題正解／事故記錄／Owner 保留：在資料庫層擋刪 |
| memory_evidence | memory_id → memories | CASCADE | PK(memory_id, term) | 逐字證據（term 必須是記憶本文的子字串） |
| injection_events | （無；與既有 injections 帳同語義，可記到已刪 id） | — | PK(event_id) AUTOINCREMENT；索引 (memory_id, at) | append-only 注入事件 |

CHECK 約束：
- memory_eligibility.state ∈ {hidden, superseded, dormant}；state='superseded' 時，superseded_by 不可為 NULL 且不可等於自己。
- memory_protection.kind ∈ {mistake_answer, incident_record, owner_keep}。

## 執行程式（逐字）

```python
    def _migrate_y2c(self):
        conn = self._conn()
        try:
            conn.execute("BEGIN IMMEDIATE")
            for ddl in self.Y2C_DDL:
                conn.execute(ddl)
            conn.execute("INSERT OR IGNORE INTO schema_meta (key, value, updated_at) VALUES ('y2c_schema', ?, ?)",
                         (Y2C_SCHEMA_VERSION, datetime.utcnow().isoformat()))
            conn.execute("COMMIT")
        except Exception:
            if conn.in_transaction:
                conn.execute("ROLLBACK")
            raise
        finally:
            conn.close()
```

## 回退（雙軌）

**DB rollback**（停服務後在 memories.db 上執行；或直接還原套用前的 `.backup` 檔）：

```sql
BEGIN IMMEDIATE;
DROP TABLE IF EXISTS injection_events;          -- 連帶刪除 idx_injection_events_mid_at
DROP TABLE IF EXISTS memory_evidence;
DROP TABLE IF EXISTS memory_protection;
DROP TABLE IF EXISTS memory_eligibility_log;
DROP TABLE IF EXISTS memory_eligibility;
DELETE FROM schema_meta WHERE key = 'y2c_schema';
COMMIT;
```

**code rollback**：`git -C /root/anchor-memory revert <套用 0001 後產生的 commit>`，或 `git -C /root/anchor-memory reset --hard 3834bdd`（S1 前的 HEAD）。
兩軌必須一起做。只做 DB rollback 的話，下次開庫 `_migrate_y2c()` 又會把表建回來；只做 code rollback 的話，表會留著，但舊程式不讀，行為不受影響。

## 驗證（套用前後）

- parity：正式版程式（3834bdd）、staging-S1（222b5bd）、staging-HEAD（旗標全關）三者連續跑，**逐位相同**。比對範圍：102 次 search、wakeup、5 次 consolidate、decay。
- 紅測 T1：先放一個同名 VIEW，讓第六句（建索引）失敗 → 前四張表都不得落地、schema_meta 不得有 y2c_schema。舊版 S1（逐句自動提交）在這條測試上是紅的；新版是綠的。變異 M56（拿掉 BEGIN IMMEDIATE）必紅。
