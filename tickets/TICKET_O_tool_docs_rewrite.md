## 官方機制拆解（本單依據）

1. **觸發句導向**：說明不是講功能，是講「什麼時候用／什麼時候不要用」（use when X / NOT for Y）。
2. **說明跟著工具走**：每個 session 工具 schema 自帶說明，不依賴記憶——cn 換窗後不用重教。
3. **分層**：索引輕（一句話）＋細節按需（mumu_tool_help 已是這個形狀，強化它）。
4. **就地提醒**：在對的情境給一句提示，而不是開場塞一大篇。
