## Y1：評測基建（先於一切行為改動；純新增，不動召回）

1. **錯題集**（Scarlett 制）：Owner/規劃窗點過的每一個召回錯誤存檔（該召沒召/不該召召了/召錯條），一題一條、快照不隨記憶庫改動。來源：歷史事故（9/24 壓縮失真誤補、cap5 前留言堆積等）先入庫當種子。
2. **測評集**：三類題各≥10 題用合成或已脫敏案例——閒聊不該召／該召哪條／禁止召隱藏條。改任何參數先過整套。
3. **調參台雛形**：融合/排序抽成純函數（零依賴、能單測、能離線掃參）；參數熱載（檔案制，不重啟服務）；生產與調參共用同一份裝配核不漂移。
4. 本階段驗收：評測集對現行系統跑出基線分數（含失敗題清單）——這就是 P1b 的「先破」。
5. 【小踢修訂】**證據二重現與資料完整性檢查**（隔離快照上，只查不修）：injections 孤兒清點、edges 外鍵完整性、嘗試重現 FOREIGN KEY constraint failed 的觸發條件；產出資料完整性報告。
6. 【小踢修訂】link-quality 雙向量測：評測不只量誤連（寬度），也量**漏連／零邊孤島**（如 2026_09_25_diary_memory_ruling 案例）——避免 Y2 縮窄連結後反而惡化 recall。

## Y2：召回修復＋排序器（憑 Y1 基線開工；小踢 10/1 核定分階順序）

**施工順序（小踢 10/1 裁定、10/2 細化，不可倒置）：Y2a candidate generation → Y2b no-recall semantic gate＋雙榜 RRF → Y2c eligibility＋證據式遺忘＋durable cooldown。另列兩個獨立驗收面：link-quality／strong-edge formation（新邊如何長出可信可達的強連結）、vector-memory lifecycle integrity（含 decay_short 只刪表不刪向量）。**

1. **Y2a candidate-generation correctness**（小踢升格的正式修復項；RRF 不能替代這層）：中文切詞修正（jieba 兩側對齊、單一中文字不做 OR LIKE 裸匹配）、關鍵字後援分數不再固定 0.6、所有查詢 LIMIT 配 ORDER BY（可重現）。每項改動對 Y1 基線跑回歸。
2. **Y2b 雙榜（語義＋關鍵詞）RRF** 按名次融合，只看名次不看分數；含**哨兵／語義門檻／寧缺毋濫閘**（先判斷「這句話該不該翻記憶」——10/2 基線揭示：閒聊誤召全來自向量榜、距離門檻收緊也救不了，缺的是這道閘；S-chitchat-02 歸因由「單字 LIKE」更正為向量撈取）；哨兵失敗不靜默退直連留日誌（Scarlett）。
3. **Y2c-0 eligibility 硬過濾**（小踢 10/2 拆層）：hidden 條目一律**不得進被動召回候選**（hard filter，不是降權——基線證明降權擋不住向量直召）；已更正條目建立 **superseded／替代語義**（搜到舊條給新條）。只有具召回資格者才進下一層的遺忘與降層。
4. **Y2c-1 證據式遺忘**（SM 制，適配我們）：記憶附逐字關鍵詞證據；長期未在她的訊息中再現者降層（降層≠刪除，救生索保留）；pinned 與 core 永久豁免。90 天閾值先抄後調。
5. **Y2c-2 durable cooldown 全入口統一**（小踢改定義）：不只寫穿資料庫（進程重啟不復燙）——所有會產生召回／注入的入口（search、wakeup、consolidate）統一走同一套 durable cooldown 判定；挖掘/注入自我回流過濾（SM：抽取時排除自己注入的內容）。另併修 **decay_short 只刪表不刪向量**（10/2 證實為 25 筆向量孤兒的製造機，injections 孤兒 3 筆全在其中；確切排序 Y2 開工時規劃窗裁）。
6. **Y2c-3 邊權重／legacy discount 整治**＋每輪路由日誌一行（翻沒翻/為什麼浮/為什麼不浮）——cn 問「為什麼想起這個」時查得到。
7. 行為改動上線流程：Y1 評測全綠＋錯題集回歸→規劃窗→Owner→小踢→才切換；舊排序器保留一鍵回退。各階段獨立過門，不打包上線。
